### Common Big-O patterns you should memorize:

###### &#x20;  *Code pattern                         Big-O*

x = nums\[0]	                                O(1)

One loop	                                    O(n)

Two separate loops	                            O(n)

Nested loop	                                    O(n²)

3 nested loops	                                    O(n³)

Binary search	                                  O(log n)

Sorting	                                         O(n log n)

Loop + sorting	                                 O(n log n)

Two nested loops over different inputs	          O(n × m)
